# Data

This folder is not versioned (see `.gitignore`), only this README.

- `raw/`: full datasets, if ever downloaded.
- `samples/`: partial samples generated by the scripts in `exploration/`.

## SignFi

- Repository: https://github.com/yongsen/SignFi (the `.mat` files are on Box, linked from its README).
- Paper: Ma et al., *SignFi: Sign Language Recognition Using WiFi*, IMWUT 2018. DOI 10.1145/3191755.
- License: non-commercial/educational/research use only, **no redistribution**. The source must be
  cited and a disclaimer included in publications and presentations.

To regenerate the samples without downloading the full files:

```bash
.venv/Scripts/python exploration/2026-10-30_signfi_inspection/signfi_remote.py sample dataset_home_276.mat csid_home 300
```
